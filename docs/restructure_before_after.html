Engineering note / acidcat v1.0b candidate

The restructure, before and after

acidcat's core/ was one flat pile of 75 modules. It is now eleven packages whose order is the dependency direction, which is what makes the install tiers real rather than aspirational. Nothing was lost doing it: the verb list, the walker registry, and the public API are byte-identical either side of the change.

What the ordering buys

The packages are listed in dependency order, and that is enforced, not merely intended. Nothing in the lean core imports analysis/ or catalogue/, so a base install is a working byte-dissection tool with a single dependency.

beforetiers by convention
# nothing stopped a core module from
# importing the heavy stack at module
# level. the tiers were a promise in
# the README.

pip install acidcat
  -> imports could still reach librosa

# and a zero-dependency capability was
# gated behind the heavy one:
detect loop_128bpm_Am.wav
  bpm  null   (filename parsing sat
  key  null    behind the librosa gate)
  exit 0 -- reported success
aftertiers by invariant
# a test walks every module under core/
# and fails on a module-level import of
# an optional stack.

tests/test_lean_install.py
  static  : no heavy imports in core/
  runtime : core verbs run with the
            stacks blocked

detect loop_128bpm_Am.wav
  bpm  128    source: filename
  key  Am     source: filename
  exit 1 only when nothing is knowable

Where each concern went

was, loose in core/nowwhy it groups
adpcm, adx, brr, brstm, cdxa, dsp, dtk, hps, ncw, vadpcm, vag→codecs/Everything that turns coded samples into linear PCM. Depends only on primitives.
aiff, riff, flac, mp3, mp4, ogg, midi, ump, svx, tracker, sf2, ni, serum, vital, bitwig, cover→formats/One parser per format, sitting parallel to the walkers built on them.
constraints, structure, edits, edit_riff, edit_aiff, repairers, countrepair, flacrepair, mp4repair, writer, midi_write→write/One idea: edit = repair = re-satisfy the constraints and re-emit.
audioscan, locate, framescan, anomalies, lsb, transforms, triage, integrity, provenance, viz→forensics/Read-only measurement. Nothing here mutates a file.
index, indexing, search, query_sql, registry, preset_meta, paths→catalogue/The library layer, and the only cross-tier dependency — it needs analysis, never the reverse.
detect, features, camelot→analysis/The second hat. The only core package that reaches for librosa, and only inside functions.
sniff, vocab, sandbox, mapped, bytefields, fieldcodec, formats→infra/Cross-cutting plumbing. formats.py became render.py here.
samples, n64rip, snesrip→extract/Pull the audio out — the read-side counterpart to write/.
gcm, wiidisc, iso9660, cue→containers/Disc images and filesystems that hold audio as files.
probe, tagged, census→stay at core/Two are the public API facade; census is a standalone survey. Grouping them would hide them.

And five that were not

The original audit flagged more duplication than existed. Each of these looked like a copy and turned out to encode a real distinction, so it was left alone. This is the part most likely to be "fixed" later by someone reading a similarity score instead of the code.

  • The IFF chunk iterator — seven loops sharing a shape, not a contract.
  • "Autocorrelation ×5" — three of the five measure different things.
  • A unified PcmResult — container and stream decoders genuinely differ.
  • The walker error contract — two correct signals, not an inconsistency.
  • Magic-byte dispatch — the checks differ in depth where it matters.

Beyond the tree

  • One word, one meaning across the CLI: format is the file's type, -o is where bytes go, --output-format is the rendering, --encoding is how carved bytes serialize.
  • Composability: - means stdin on the byte verbs, structured output on stdout with summaries on stderr, and exit codes that follow the grep family so && chains behave.
  • The TUI's blind spot closed: 32/32 actions and 11/11 screens now covered, up from 18 and 7.
  • Seven real bugs surfaced by moving the code — including a crash the full suite had never reached.
